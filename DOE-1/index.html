Statistical Framework

DOE Analysis Methodology

The statistical approach used to analyze experiments and build predictive models for each stage.

📐

Fractional Factorial (Screening)

Used in Stages 1–3 to screen key factors. A 2k-p design reduces 8–16 factor combinations to 4–8 runs while maintaining Resolution III–IV. Identifies main effects and 2-factor interactions.

All Stages
🌐

Response Surface Methodology (RSM)

Central Composite Design (CCD) used in Stages 4–6 for process optimization after screening. Builds a second-order polynomial model to find the optimal operating window for yield and purity.

All Stages
🔢

Regression Modeling

Multiple linear regression (MLR) fits the experimental data to a polynomial model. Significant terms identified using ANOVA (p < 0.05). Coefficients reveal factor importance and direction of effect.

All Stages
🎯

Desirability Optimization

Multi-response optimization using composite desirability function. Simultaneously maximizes yield and purity while keeping impurity levels below specification — finds the optimal set-point for each process.

All Stages
🔍

Pareto Analysis & Half-Normal Plots

Visualizes effect significance. Half-normal plots distinguish real effects from noise without formal hypothesis testing. Pareto charts rank factor contributions to guide the next DOE iteration.

Screening
🤖

Bayesian / Sequential Learning

After each experimental run, a Gaussian Process model updates predictions. Acquisition functions (Expected Improvement) suggest the next most informative experiment, enabling continuous optimization.
